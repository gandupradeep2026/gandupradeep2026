- **Autonomous & Telemetry Systems**: High-frequency vehicle sensor ingestion (CARLA, CAN-Bus, ISO 14229 / UDS diagnostics) coupled with streaming analytical platforms.
- **Orchestration & Quality**: Airflow DAG design, automated schema evolution, idempotent batch pipelines, and end-to-end integration testing using Beam `TestStream`.
